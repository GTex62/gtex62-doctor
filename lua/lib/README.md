# lua/lib

Thin local compatibility/helper layer, mirroring the role
[`gtex62-osa/lua/lib`](../../../gtex62-osa/lua/lib/weather_codes.lua) plays for
OSA and [`gtex62-sitrep/lua/lib`](../../../gtex62-sitrep/lua/lib/README.md)
plays for SitRep (a lookup table not worth promoting to the engine).

Empty for now. Doctor has no compatibility helpers yet; this directory exists
so future ones (e.g. a NOTE-tag-to-remediation-text lookup table) have a
conventional home instead of drifting into `lua/suite/`.
